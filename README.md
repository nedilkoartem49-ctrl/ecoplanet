# EcoPlanet — Жер планетасындағы қауіпті қалдықтар

Колледждің бірінші курсында қорғауға арналған қазақ тіліндегі интерактивті жоба. Сайт қалдықтың қоршаған ортаға әсерін түсіндіреді және оны азайту жолдарын көрсетеді.

## Іске қосу

Node.js 20.9 немесе одан кейінгі нұсқасы және npm қажет. Терминалда жобаның бумасын ашып, мына пәрмендерді орында:

```bash
npm ci
npm run dev
```

Браузерде [http://localhost:3000](http://localhost:3000) мекенжайын аш.

Дайын нұсқаны тексеру және жергілікті іске қосу:

```bash
npm run build
npm run start
```

## Қорғау режимі

1. Сайттың жоғарғы жағындағы **«Қорғау режимі»** батырмасын бас.
2. **←** және **→** пернелерімен немесе экрандағы батырмалармен сегіз слайдты ауыстыр. **Home** бірінші слайдқа, **End** соңғы слайдқа апарады.
3. **«Қалдықтарды сұрыпта»** слайдында әр қатысушыға бір зат беріп, тиісті жәшікті таңдауды ұсын. Ойында 10 зат бар, дұрыс жауапқа 10 ұпай беріледі. Компьютерде затты жәшікке сүйреп апаруға да болады.
4. Шығу үшін жабу батырмасын немесе **Esc** пернесін бас.

## Vercel-де жариялау

1. Жобаны Git репозиторийіне жүктеп, оны Vercel арқылы импортта.
2. Жоба репозиторийдің ішкі бумасында болса, **Root Directory** өрісінде осы буманы таңда.
3. **Framework Preset** өрісінде **Next.js** таңдалғанын тексеріп, **Deploy** батырмасын бас.

Сайтқа тіркелу, дерекқор, API кілті немесе орта айнымалылары қажет емес. Мәтін мен дереккөздер `components/content.ts` файлында. Жылдар мен бастапқы есептерге сілтемелер сайттың «Дереккөздер» бөлімінде берілген. Жер мен қоқыс үйіндісінің суреттері — жобаға арнап жасалған иллюстрациялар.
